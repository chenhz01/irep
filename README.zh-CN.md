## 费曼导读 — 先读这段（60 秒）

**这是什么？**
IREP 是一把尺子。指向任何系统——开源代码、二进制固件、甚至一整套物理理论——它用可度量的尺子而不是感觉回答三个问题：*法律上能不能碰？吸收了它的机制说不说？做出来是真二代还是换皮？* 尺子以两种形态随仓发布：一台可跑的判决机（`gate/irep_gate.py`）+ 一份成文规则（`spec/`）。

**为什么和你有关？**
「我能不能在这个系统上做东西而不被骂抄袭」——多数团队靠感觉、律师费或运气回答这个问题。IREP 用四把尺（许可证/署名/差异度/工业验收）加四个公开实证回答，全部可在几分钟内复跑。其中第一个实证，是尺子量**它自己**。

**你该怎么办？**
克隆本仓，跑 `python gate/irep_gate.py`，然后把尺子指向你自己的下一个项目。如果它判 `BLOCKED`，相信它——那是筛子在工作，不是尺子失灵。

## 三个问题，与回答它们的机器

你发现一个值得站在其肩膀上的系统。难点从来不是看懂它，是三个问题：

1. **法律上能不能碰？**（许可证闸）
2. **用了它的机制，说不说？**（署名闸）
3. **做出来是真二代，还是换皮？**（差异度闸）

`irep_gate.py` 同时打四把尺——L1 许可证矩阵 / L2 指源完备率 / L3 差异度 `r = 新增/保留` / L4 工业验收件——只返回一个词：`BREAKTHROUGH` / `DERIVATIVE` / `REPLICA` / `BLOCKED`。

**尺子量的第一件东西，是它自己：**

| 候选 | L1 法律 | L3 差异度 | 判决 |
|---|---|---|---|
| IREP 第二代（本协议自身） | MIT ALLOW | r = 1.143（保留 7 / 新增 8） | **BREAKTHROUGH** |
| `morluto/rea` 换皮克隆（反面对照） | MIT ALLOW | r = 0.053（保留 19 / 新增 1「中文界面」） | **REPLICA** |

注意第二行：它**法律上完全合法**，照样判换皮。这把尺量的不是法院，是成色。

## 实证一 · 费曼双缝：「预测等价」是可证明的

可跑：`proofs/anchor_codec.py` · held-out 校验，独立复跑 exit 0。

**输入只给四条假设**——叠加原理 / 相因子 exp(iS/ℏ) / 玻恩定则 / 幺正性；**明令禁止**薛定谔方程、哈密顿算符、能级量子化。从这四条出发，重建整台量子力学机器。

**然后预测假设里根本没有的现象（held-out）：**

| held-out 现象 | 预测 vs 真值 | 相对误差 |
|---|---|---|
| Pöschl-Teller 束缚谱 | −9.787791 vs −9.78774 | 4×10⁻⁸ |
| 谐振子零点能 ½ℏω | 全过 | 2×10⁻⁶ |
| 自由波包色散 | 全过 | 1.8×10⁻¹⁵（机器精度） |
| 无解析解的非谐振子 ½x²+0.1x⁴ | 三方交叉 | 1×10⁻⁷ |

**14 项 held-out 预测全过，最大相对误差 1.97×10⁻⁶。**

它回答一个根基问题：严格「无损还原」被香农/柯尔莫哥洛夫下界禁止——但**「预测等价」不是**。信息不在锚点里，在约束里；只存锚点不存约束 = 必然有损。双缝恰好是量子力学的生成元级锚点（费曼本人早把双缝→N缝→路径积分→薛定谔→海森堡的还原链修成了公路），所以在这一个点上，「降维到 12 岁孩子能懂、再无损升维回来」不是修辞，是机器打印出来的数字。

建造者自白，留在记录里：机器三次比建造者更可靠——参照式漏 ½ 归一化、收敛阶参照系标错、测量法引入常数偏置。机器没有「我觉得应该对」这个环节。

## 实证二 · 多数系统有主：判死是筛子，重建是活路

值得逆推的系统，**九成有主的**：厂商在营、EULA 禁逆向、法务全年无休。对它们，「逆推」两个字写在简历里都寒碜。

判决机对一家在营的专有图像软件厂商只有两行：L1 DENY（专有 EULA 禁逆向、版权人活跃维权），场景闸 G6：版权人在营——不适用孤儿豁免。**`BLOCKED`——问题不是尺子不够严，是场景错了。**

**所以 BLOCKED 不是墙，是筛子。** 一百个候选进来，闸机一分钟砍掉九十个「有主」的——省下来的不是时间，是法人身份。一把恒判 PASS 的尺子是摆设；能判死的尺子才配叫闸门。

同一把尺换个对象就活了：一台孤儿工控固件（原厂破产、设备持有者授权）→ `CONDITIONAL-BREAKTHROUGH`，四个前提缺一即不放行：孤儿事实可证 / 持有者授权 / 仅互操作维护（不复制不分发原代码）/ 保留原版权声明。记住一句：**「没人维护」≠「无主」。**

但对有主系统也完全干净的第三条路，才是本协议的真正核心机制：

> **重演重建（Re-derivation）：不看它的代码，只看它的行为；提取约束，用自己的实现满足同一批 held-out 预测。**

四步，缺一不可：

```
① 观察面      → 黑盒可观察行为（输入/输出/公开规格），零代码接触
② 约束提取    → 从行为归纳「为什么必然成立」的不变量（不是抄实现）
③ 原生重建    → 全新实现，不引用、不派生、不改写原代码一行
④ held-out 对拍 → 用锚点里没有的现象证明预测等价（否则只是自称）
```

法律边界说老实话：互操作目的的黑盒行为观察在多数法域存在**有条件的合法空间**（欧盟软件指令第 6 条、DMCA §1201 互操作例外），但边界高度依赖场景与法域——**本文是工程协议，不是法律意见**，落地前必须律师确认。能确定的是：**不碰代码的重建，从源头不存在版权派生问题**——你写的是自己的实现。

## 实证三 · 费马大定理：被垄断 358 年的「知识」，逆推回来的是知识点本身

可跑：`proofs/flt_rederive.py` · 四节点全 PASS，零查表，独立复跑 exit 0。

数学史上最硬的一个「专利」：1637 年费马在书页边写下定理却不给证明，让全人类猜了 **358 年**。IREP 对它做了一次完整的逆推 + 还原：**不抄任何人的证明，只提取四代数学家各自提取的「约束」，用机器自己重新算出来。**

| 节点 | 约束（不是证明，是不变量） | 机器实算（held-out） |
|---|---|---|
| H1 费马 1637 | n=4 无穷下降——任何解必生出更小的解 | 下降机在无解环境无输入可降，与命题一致 |
| H2 库默尔 1850 | 唯一分解在分圆域何时失效 | 伯努利数现算：p<100 仅 37 非正则（37\|B₃₂）；最著名「不合常理整除」691\|B₁₂ 复核为真 |
| H3 弗雷→谷山-志村→怀尔斯 | 算术命题 ⟺ 几何对象的模性 | 机器**只看点计数序列**，自学出 CM 结构，预测训练集没有的 p∈[41,100)：**13/13 全中** |
| H4 热尔曼 1823 | case-1 判据 + 一个被笔名擦掉的名字 | p<200 的 15 个热尔曼素数现算，7 个素数 case-1 机械核查全过 |

H3 是全场最锋利的一刀：**机器没被告知任何 CM 理论**——它只看到椭圆曲线的点计数行为，自己归纳出「p = a²+b² 的两半决定 a_p」的约束，然后预测了它从没算过的素数。

逆推回来的不是「证明的复制品」，是五条**知识点**（重组产物，非原素材直抄）：①难点从 n=4 起暴露 ②库默尔转折「唯一分解何时死」 ③弗雷飞跃算术⟺几何 ④怀尔斯封顶藏起来做七年 ⑤**知识民主化的铁证——证明一旦发表，任何人都能独立验证：定理无法被垄断，能被垄断的从来只有「谁来过」**。

第 5 条是 H4 节点存在的理由：热尔曼的贡献真实存在，却被笔名与时代规则擦掉了名字（高斯称她「Monsieur Le Blanc」）。**IREP 的署名闸（L2）不是礼节，是历史用血写下的补丁**——逆推者必须署名自己吸收了谁的约束，同样也必须让后来者能署名你的。

**定理无法被垄断，能被垄断的只有过程与署名。IREP 把两者都拆开：过程进公版（held-out 对拍人人可复跑），署名进台账（THIRD_PARTY_NOTICES 一条不漏）。**

## 附录 · 飞控黑盒重演重建（工业面）

可跑：`proofs/ctrl_rederive.py` · held-out 三场景 RMSE < 9.1mm，独立复跑 exit 0。

台架上一台黑盒高度保持飞控（隐藏 Kp=2.2 / Ki=1.4 / 限幅 1.50 m/s / 积分限幅 ±5），重建方**只看阶跃响应**，零固件接触。重建方拟合出 Kp=2.2 / Ki=1.4 / 限幅 1.49；held-out 设定点（2.5m / 4.0m / 2m+阵风）全过。途中机器判死建造者两处测量法缺陷（一阶对象纯 P 也能零稳态差，稳态误差不是积分作用的证据；斜率最小值不是限幅平台，最大值才是）。

**等终性警告（强制随附）：行为对拍全过 ≠ 参数恢复**——多组 (Kp, Ki, rl) 给出同一批轨迹。IREP 传的是预测等价，不是源码。工业控制系统的可逆推覆盖率分三层：约束层（公开）/ 调参层（可逆推）/ 数据层（十万飞行小时，不可逆推——在时间不在约束里）。本附录证明的是「哪几层理论上可传」，**不是许可去碰任何厂商产品**——场景闸对那些照判 DENY。

## 逆转模式 — 尺子的第二刀

> 尺子量的第一件东西是它自己。第二刀，量它自己的公开面——因为你发布的那一刻，你的仓就成了别人的参考系统。

角色对调：同一台判决机，参考与候选互换——候选是*他们*在我们公开面上的建造。三个判例，全部可复跑：

| 逆转候选 | L2 署名 | L3 差异度 | 判决 |
|---|---|---|---|
| 邋遢克隆（保留 11 + 加 1 壳，出处不登记） | 82% → FAIL | r = 0.091 | **DERIVATIVE**——补齐署前方可对外 |
| 干净克隆（同上，文书齐全 + 专利意图） | 100% PASS | r = 0.091 | **REPLICA**——合法、完备、照样换皮；触发 prior-art 警报 |
| 真二代（保留 4 + 新增 6 维度） | 100% PASS | r = 1.5 | **BREAKTHROUGH**——协议欢迎，设计如此 |

协议不挡学习，挡的是换皮称二代。发布方的旅程是五阶段倒着跑：

```
R5 署名审计 → R4 差异度设防 → R3 约束公版 → R2 暴露面清点 → R1 放行条件
```

承重的那道算术：最低成本复刻者保留全部 11 条公开机制 + 加一个壳，r = 1/11 ≈ 0.091——深陷 REPLICA 带。公开面本身就是护城河。

可跑：`gate/irep_gate_reversed.py`（仅标准库；退出码可当 CI 门——0 = R1-R5 全过）。全文见 `spec/REVERSED-MODE-v1.0.md`，含逆转硬闸 **R-G1**：暴露面审计必须机器产出——「我觉得没露」是 G7 治过的同一种病。

## 第五尺与第六尺 — 量「刚生成出来的东西」（规范 v1.1.0）

v1.0 那四把尺量的是**已经存在的系统**。这两把量的是**刚刚生成出来的东西**——你写的，或者一个自动研究循环写的。

- **第五尺 · 涌现**：一条推理链里，有没有参考链中不存在的原子？五态判决：`HALLUCINATION`（步骤带着没挣到的前提）/ `DRIFT`（离开了参考却没到任何地方）/ `ECHO`（用参考里已有的原子重新推出）/ `EMERGENT`（带着一个挣到的新原子）/ `UNKNOWN`（证据判不了，就说判不了，别猜）。
- **第六尺 · 做对事**：判决是在开工**之前**形成的吗？契约是 `manifest 进 → 退出码出`，五问 Q1–Q5，外加尺文件的 sha256 锁——防止临跑之前把尺偷偷改小。

**两把尺目前都以规范形式发布。** 参考实现写过、跑过，但**不在本仓库**；`spec/G9-emergence-and-do-right-v1.1.md` 第 4 节写明了这一点，文档里全部数字在代码落地前都标为未验证。中文方法论全文（含实测分布，以及那道「机器全绿但语义判错」的边界展品）见 `docs/EMERGENCE-v1.1.zh-CN.md`。

**成对 star 才构成完整论证**：本仓证明尺子是诚实的（它判了自己），隔壁仓证明尺子是有用的（它省了可测的钱）。单看任一个，都只是主张；两个一起看，才是证据。

**我们不会做的事**：换星（star-for-star）、买推荐位、「关注回关」、在读者还没跑过任何命令前就求 star。star 数是唯一无法伪造的反馈信号——把它换掉，等于把自己的仪表砸了。

**star 之后你会得到什么**：有新实证入库时的发布说明；issue 优先被读（仍是 48 小时目标，但 star 用户的先读）；以及「五个路线方向先做哪个」的一票。

## 上热门保证 — 一个我们真能守住的保证

<!-- FGA4:trending -->
「保证上热门」这句话，没人能兑现：排名由平台算法决定，不由作者决定。承诺你控制不了的结果，是营销；承诺你控制得了的结果，才是契约。所以下面是可证伪的版本。

| # | 承诺 | 怎么验证 | 违背了怎么办 |
|---|---|---|---|
| 1 | 本仓每个数字都可复跑 | 任何没有命令支撑的宣称都是 bug，欢迎报 | 7 日内修正或删除 |
| 2 | 每个判决都可以用同一件工具重跑来质疑 | 你可以自己跑出不同结论 | 在 `docs/` 发勘误，署你的名 |
| 3 | issue 48 小时内首次回应 | issue 时间戳 vs 首次回复时间 | 超时我们公开说明 |
| 4 | 不宣称没有证据的采用量 | 我们不发布查不到来源的使用数据 | 撤回该宣称 |
| 5 | 随时可以取消 star，不用解释 | 你的 star 不是跟我们的合同 | ——（这正是重点） |

**在这个仓里，「上热门」的诚实含义**：我们不承诺榜单名次、不承诺 star 数、不承诺算法加权——这些我们控制不了，而一个敢承诺它们的仓库，等于在告诉你它和证据的关系。我们承诺的是那些**导致**热门的因素：值得读的第一屏、经得起手算的数字、会回话的维护者。如果你跑完之后觉得它不配一个 star，正确做法是不给，并在 issue 里告诉我们为什么。

**证伪实验，先说在前面**：把 `## 复跑一切` 里的三条命令跑一遍。如果任何一条在干净的 Python 3.10+ 环境里失败，这份保证作废，是仓库错了——不是你的环境有问题。
