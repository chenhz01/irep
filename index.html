Industrial Reverse-Engineering Protocol · v1.3.0

IREP

A ruler for the question teams usually answer with vibes, legal bills, or luck: may I build on this system, must I say so, and is what I ship a genuine second generation?

"We built a ruler that can judge a system to death. The first thing it measured was itself."

One word, four scales

irep_gate.py measures license, attribution completeness, difference degree and industrial acceptance, then prints BREAKTHROUGH / DERIVATIVE / REPLICA / BLOCKED.

Four held-out proofs

Double-slit prediction equivalence, owner/sieve filtering, Fermat re-derivation, and a black-box flight-control rebuild. All re-runnable, stdlib except two simulations.

Judge before you build

G8 is fail-closed: weapons, malware and unauthorized surveillance are out of scope regardless of intent. The boundary is on the first page, not the last.

Thirty seconds in

git clone https://github.com/chenhz01/irep
cd irep
python gate/irep_gate.py          # four contrast verdicts, stdlib only
pip install .                    # optional: exposes the CLI entry points
irep-gate --json                 # same gate, machine-readable

Two simulation proofs need pip install "numpy>=1.20" (or pip install ".[proofs]"). The gate and the Fermat proof never do.

Honest status

The four v1.0 scales are fully runnable. Scale 5 and 6 ship as specification only — their reference implementations were exercised but are not in this repository; treat the numbers in that document as unverified until the code lands. Every number elsewhere has a command attached; if one fails on a clean Python 3.10+ install, that is a bug worth an issue.
